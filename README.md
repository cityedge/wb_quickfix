# WB QuickFix 1.0.5

WB QuickFix は、JPEG / PNG / BMP のホワイトバランス修正を中心にした軽量画像レタッチアプリです。

基本操作は、本来は白またはグレーである場所をクリックして、その場所を基準に色かぶりを補正することです。必要に応じて、色温度・色偏差・自然補正と、明るさ・コントラスト・彩度・色相・ガンマを追加調整できます。

UI は日本語 / English の切り替えに対応し、ダークテーマを採用しています。

## 主な機能

- JPEG / PNG / BMP の読み込み・保存
- 画像ペインへのドラッグ＆ドロップ
- 画像未読込時は、画像ペインをクリックしてファイルを開ける
- 自動WB：元画像全体から白・グレーらしい領域を複数抽出し、その色分布の中心を白基準としてホワイトバランスを補正
- 白スポイト：本来は白または無彩色グレーである場所を基準にホワイトバランスを補正
- 肌スポイト：肌色を基準にした実験的な弱い色補正
- 色温度：-100 ～ +100 の相対値
- 色偏差：-100 ～ +100
- 自然補正：0 ～ 100
- 明るさ、コントラスト、彩度、色相、ガンマ
- ホワイトバランスだけを初期化する `Reset` ボタン
- 基本補正だけをまとめて初期化する `Reset` ボタン
- すべての補正を常に「読み込んだままの元画像」から再計算
- 1回 Undo
- `オールリセット` ですべての補正を初期化
- `Original` ボタンを押している間は元画像を全面表示
- 画像ペインを右クリックしている間は、クリック位置を境界に「左＝処理後 / 右＝元画像」で分割比較。右ボタンを押したまま左右へドラッグして境界を移動可能
- ズーム、全体表示、ドラッグ移動
- JPEG 品質設定
- PNG 圧縮レベル設定
- JPEG 品質 / PNG 圧縮レベル / UI 言語を次回起動時に復元
- PNG の Alpha チャンネルを維持
- EXIF Orientation を反映
- ICC Profile / EXIF / DPI を可能な範囲で引き継ぎ

詳しい使い方は [USER_GUIDE.md](USER_GUIDE.md) を参照してください。

## 動作環境

ソースから実行する場合：

- Windows 10 / 11 を想定
- Python 3.10 以降
- PySide6
- NumPy
- Pillow

依存バージョンは `requirements.txt` に記載しています。

## 起動方法

もっとも簡単なのは `run.bat` をダブルクリックする方法です。

初回起動時のみ `.venv` を作成し、必要な Python パッケージをインストールします。

手動で起動する場合：

```bat
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## EXE の作成

`build_exe.bat` を実行すると、PyInstaller の `--onedir --windowed` 方式でビルドします。

生成先：

```text
dist\WB_QuickFix\WB_QuickFix.exe
```

## 基本的な使い方

1. JPEG / PNG / BMP を開きます。
2. まず `自動WB` を試すか、`白を指定` で基準点を手動指定します。
3. 必要なら色温度、色偏差、自然補正を微調整します。
4. 必要なら明るさ、コントラスト、彩度、色相、ガンマを調整します。
5. ホワイトバランスだけ戻す場合は `ホワイトバランス` 見出し右側の `Reset`、基本補正だけ戻す場合は `基本補正` 見出し右側の `Reset` を使用します。
6. `Original` で元画像を全面表示するか、画像ペインを右クリックして「左＝処理後 / 右＝元画像」の分割比較を行います。右ボタンを押したまま左右へドラッグすると境界を移動できます。
7. 保存形式を選び、`名前を付けて保存` します。


### 自動WBについて

`自動WB` は、読み込んだままの元画像を縮小解析し、画像全体から「白またはグレーらしい」領域を複数抽出します。単一の「最も白い場所」を選ぶのではなく、明るさ・局所的な安定性・色の偏りなどから候補群を作り、明らかな外れ値を除いたうえで、その色度分布の中心を白基準として色温度・色偏差・自然補正を更新します。

このため、画像全体に赤・黄・青などの色かぶりが乗っている場合でも、白候補群そのものが同じ方向へずれていれば、そのずれを照明色として補正する方向に動きます。暖色照明の室内写真でも、暖色を雰囲気として残すのではなく、白い物体が白に近づく方向へ補正することを意図しています。自動判定が合わない画像では、`白を指定` で基準点を手動指定してください。

## 重要な設計仕様

白スポイトや各スライダーの補正は、直前の編集結果へ重ねて適用されるわけではありません。

常に、読み込んだままの元画像と現在のパラメータから再計算します。そのため、白スポイトを複数回使った場合も、毎回クリック位置の「元画像上の色」を基準に新しいホワイトバランス値を算出します。

## 対応形式の補足

### JPEG

- 読み込み・保存対応
- 保存品質 70 ～ 100
- 透明度は扱えないため、Alpha を持つ画像を JPEG へ保存する場合は白背景へ合成します

### PNG

- 読み込み・保存対応
- Alpha チャンネルを維持
- 圧縮レベル 0 ～ 9
- PNG の圧縮レベルは画質ではなく圧縮率と保存時間に影響します

### BMP

- 読み込み・保存対応
- 保存時は互換性を優先した 24bit RGB
- Alpha を持つ画像を BMP へ保存する場合は白背景へ合成します

### 256色 / 16色などの画像

パレット画像も読み込めますが、内部では通常の RGB / RGBA へ展開して処理します。保存後に元の 256色・16色パレット形式へ自動的に戻す機能はありません。

## ショートカット

- `Ctrl + O`：開く
- `Ctrl + Shift + S`：名前を付けて保存
- `Ctrl + Z`：1回戻す
- `Ctrl + R`：オールリセット
- `Esc`：スポイト解除
